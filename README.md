# cv.aymeric.lefeyer.fr

My personal CV, built as a dynamic web app and hosted on Firebase.

Data is fetched at runtime from a dedicated API — no hardcoded content.

## Stack

- React 19 + TypeScript + Vite
- Plain CSS (no framework)
- Firebase Hosting

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Automatically deployed to Firebase Hosting on every push to `master` via GitHub Actions.
